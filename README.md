## 換照片、改文字（後台）

1. 打開後台 → https://fooicebo-wq.github.io/home-style-quiz/admin.html
2. **換照片**：點任何一張圖 → 選你的案場照片
   - 自動**置中裁成正方形**、縮到 640px、轉 JPEG，不必事先修圖
   - 也可以直接把圖**拖進格子**
3. **改文字**：題目標題、選項名稱直接在輸入框改；
   結果卡的 16 種原型在頁面最下方，點標題展開編輯（改過的會標成金色）
4. 按 **預覽測驗** 確認畫面
5. 按 **匯出 content.js** → 下載的檔案**覆蓋**資料夾裡的 `content.js`
6. 用下面「上線更新」把它推上去

**不必一次換完。** 沒換照片的格子會自動用內建插圖，混著用尺寸也一致。
原型文字同理，只改「一句標語」也可以，其他欄位沿用預設。

### 生成時踩到的坑（要重生時記得）

- **只寫「medium shot, centered」擋不住模型加道具**——會自己生出花瓶、長凳、整套沙發。
  一定要下負向約束：`the wall is completely empty, no furniture, no plants, nothing else at all`
- **錨點提到「窗戶」，模型就會生出整個客廳**。燈具組第一版就是這樣毀掉的，
  改成「完全空的房間、沒有窗戶」才乾淨
- 桌燈類（燭台、陶土桌燈）跟「不准有桌子」會打架，要改寫成「放在單一基座上」
- 要生 **1:1 正方形**，直式會被裁掉上下
- **不要指名 Eames、Barcelona 等真實名椅**，有設計權風險，用描述性寫法

`Gemini生成指令.md` 裡有全部 56 段指令（給人手動貼 Gemini 用的版本）。

## 上線更新

換完照片、覆蓋好 `content.js` 之後，在資料夾裡執行：

```bash
cd "E:/★★★Claude 資料總存區/居家風格測驗" && git add -A && git commit -m "更新照片" && git push
```

推上去後約 **1～2 分鐘**線上就會更新（GitHub Pages 要重建）。
沒更新的話按 Ctrl+F5 強制重新整理。

### 後台的其他按鈕
- **匯入**：把舊的 `content.js` 讀回後台繼續編輯（換電腦、或草稿被清掉時用）
- **全部清除**：清掉草稿回到預設，已匯出的 `content.js` 不受影響

### 容量上限
草稿存在瀏覽器的 localStorage，上限約 5MB，後台頂端會顯示目前容量。
64 格全換成照片約 1～1.5MB，正常用不會爆。超過會擋下來並提示。

## 測驗機制

- 8 題，每題 8 個選項；第 6 題是色票（不能換照片）
- 每個選項綁 **2 個價值標籤**：主標籤 +2、副標籤 +1，再乘題目權重
- 題目權重遞減：**1.3 → 1.3 → 1.0 → 1.0 → 0.9 → 0.8 → 0.7 → 0.6**（前面的題目影響力大）
- 價值共 10 軸：沉靜、秩序、溫度、自然、工藝、個性、玩心、社交、質感、機能
- 16 種原型各綁 2 個價值，比對公式：`主值×2 + 副值×1`，取最高分
- 排第 2 名的顯示為「你的另一面」

改計分只要動 `quiz-data.js` 裡的 `v: ["主","副"]` 和 `w`（權重）。

## 導流與追蹤（原版沒做的部分）

### LINE
結果頁的 LINE 按鈕會**把測驗結果直接帶進訊息裡**，客人一按送出，你收到的訊息長這樣：

> 我的居家原型是【木作職人派・Wood Artisan】
> 「好東西，值得等」
> 想聊聊我家可以怎麼做。

LINE 帳號改在 `quiz-data.js` 的 `CONFIG.lineOA`（或後台的「品牌設定」）。
目前設定：`%40608iofzm`（@ 要寫成 `%40`）。

### 追蹤事件
`track()` 會同時送三個地方，有裝就會收到，沒裝也不會出錯：
- **GA4**（`gtag`）
- **FB Pixel**（`fbq`）
- **`postMessage` 給外層網頁** ← 嵌在別的網站的 iframe 裡也追蹤得到

送出的事件：`quiz_start`、`quiz_answer`、`quiz_complete`、`quiz_share`、`quiz_cta_line`、`quiz_cta_site`。
`quiz_complete` 帶 `result`（原型）和 `path`（他一路選了什麼），可以直接看出哪種客人最多。

要收 iframe 的事件，在外層網站放：

```js
window.addEventListener('message', e => {
  if (e.data && e.data.source === 'gis-quiz' && window.gtag) {
    gtag('event', e.data.event, e.data.params);
  }
});
```
