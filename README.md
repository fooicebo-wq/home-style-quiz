# 集思居家風格測驗

參考 purely2006 的「生活測驗」做法，但機制與內容全部重寫成集思自己的版本。
純靜態網頁，**沒有後端、沒有資料庫、沒有月費**，丟到 GitHub Pages 或任何空間就能跑。

---

## 檔案結構

| 檔案 | 做什麼 | 你會不會動到 |
|---|---|---|
| `index.html` | 測驗本體（版面 + 計分邏輯） | 改配色時才動 |
| `quiz-data.js` | 題目、16 種原型文字、預設插圖 | 要改結果文字時動這裡 |
| `content.js` | **後台匯出的覆寫檔**（照片、標籤、題目） | 後台自動產生，直接覆蓋 |
| `admin.html` | **後台**：換照片、改文字 | 你平常只開這個 |

`content.js` 不存在或是空的也能正常運作，測驗會自動用 `quiz-data.js` 的內建插圖。

## 換照片（你要的後台）

1. 用瀏覽器打開 **`admin.html`**
2. 點任何一張圖 → 選你的案場照片
   - 自動**置中裁成正方形**、縮到 640px、轉 JPEG，不必事先修圖
   - 也可以直接把圖**拖進格子**
3. 想改題目文字或選項名稱，直接在輸入框改（會即時存草稿）
4. 按 **預覽測驗** 確認畫面
5. 按 **匯出 content.js** → 把下載的檔案**覆蓋**資料夾裡的 `content.js`
6. 上傳／推上網站，完成

**不必一次換完。** 沒換照片的格子會自動用內建插圖，混著用也不會怪。

### 後台的其他按鈕
- **匯入**：把舊的 `content.js` 讀回後台繼續編輯（換電腦、或草稿被清掉時用）
- **全部清除**：清掉草稿回到預設，已匯出的 `content.js` 不受影響

### 容量上限
草稿存在瀏覽器的 localStorage，上限約 5MB，後台頂端會顯示目前容量。
64 格全換成照片約 1～1.5MB，正常用不會爆。超過會擋下來並提示。

## 測驗機制

- 8 題，每題 8 個選項；第 6 題是色票（不能換照片）
- 每個選項綁 **2 個價值標籤**：主標籤 +2、副標籤 +1，再乘題目權重
- 題目權重遞減：**1.3 → 1.3 → 1.0 → 1.0 → 0.9 → 0.8 → 0.7 → 0.6**（前面的題目影響力大）
- 價值共 10 軸：沉靜、秩序、溫度、自然、工藝、個性、玩心、社交、質感、機能
- 16 種原型各綁 2 個價值，比對公式：`主值×2 + 副值×1`，取最高分
- 排第 2 名的顯示為「你的另一面」

改計分只要動 `quiz-data.js` 裡的 `v: ["主","副"]` 和 `w`（權重）。

## 導流與追蹤（原版沒做的部分）

### LINE
結果頁的 LINE 按鈕會**把測驗結果直接帶進訊息裡**，客人一按送出，你收到的訊息長這樣：

> 我的居家原型是【木作職人派・Wood Artisan】
> 「好東西，值得等」
> 想聊聊我家可以怎麼做。

LINE 帳號改在 `quiz-data.js` 的 `CONFIG.lineOA`（或後台的「品牌設定」）。
目前設定：`%40608iofzm`（@ 要寫成 `%40`）。

### 追蹤事件
`track()` 會同時送三個地方，有裝就會收到，沒裝也不會出錯：
- **GA4**（`gtag`）
- **FB Pixel**（`fbq`）
- **`postMessage` 給外層網頁** ← 嵌在別的網站的 iframe 裡也追蹤得到

送出的事件：`quiz_start`、`quiz_answer`、`quiz_complete`、`quiz_share`、`quiz_cta_line`、`quiz_cta_site`。
`quiz_complete` 帶 `result`（原型）和 `path`（他一路選了什麼），可以直接看出哪種客人最多。

要收 iframe 的事件，在外層網站放：

```js
window.addEventListener('message', e => {
  if (e.data && e.data.source === 'gis-quiz' && window.gtag) {
    gtag('event', e.data.event, e.data.params);
  }
});
```

## 本機測試

```bash
python -m http.server 5211 --directory "E:/★★★Claude 資料總存區/居家風格測驗"
```

然後開 http://localhost:5211/admin.html

> 用 `python -m http.server` 而不是直接雙擊 html：後台要存草稿（localStorage），
> `file://` 開啟時部分瀏覽器會擋。上線後是 https 就沒這問題。

## 已知限制

- **色票題不能換照片**（它本來就是色塊，不是圖）
- **16 種原型的文字要直接改 `quiz-data.js`**，後台目前只管照片、選項名稱、題目標題
- 照片存在 `content.js` 裡（base64），64 張全換約 1～1.5MB。想更輕可以改成放圖片網址：
  把 `content.js` 裡的 `"img": "data:image/jpeg;base64,..."` 換成 `"img": "images/xxx.jpg"`
